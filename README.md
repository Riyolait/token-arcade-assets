# token-arcade-assets

Ce dépôt est **public** et sert uniquement à héberger les visuels publiés (ou sur le point d'être publiés) par **Token Arcade** sur les réseaux sociaux, afin de leur fournir une URL publique stable.

## Organisation

Les fichiers sont rangés sous :

```
posts/AAAA-MM-JJ_slug.ext
```

## Règles

- Ce dépôt ne doit **jamais** contenir de secrets, de clés, d'identifiants ou tout autre élément sensible.
- Ce dépôt ne doit **jamais** contenir de brouillons ou de contenus non destinés à la publication.
- Ces éléments restent dans le dépôt privé.
